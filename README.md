
# Portafolio Personal

## Estudiante
Richard Vaca

## Descripción
Este proyecto es un portafolio personal desarrollado
para la asignatura Programación de Sistemas Web.

El sitio presenta información sobre mí, mis
habilidades, proyectos realizados y una sección
de contacto.

## Tecnologías utilizadas
- HTML5
- CSS3
- Git
- GitHub

## Secciones del sitio
- Inicio
- Sobre mí
- Habilidades
- Proyectos
- Contacto

## Cómo visualizar el proyecto

1. Descargar el repositorio desde GitHub.
2. Descomprimir la carpeta del proyecto.
3. Abrir el archivo index.html en un navegador.

## Características
- Diseño adaptable a diferentes pantallas.
- Menú de navegación.
- Tarjetas de proyectos.
- Efectos visuales con CSS.
- Formulario de contacto demostrativo.
